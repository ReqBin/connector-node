# @reqbin/connector (Node.js)

Local agent that bridges browser HTTP(S) requests to resources in local nwtwork and returns the response back to the browser. Implements the API defined in [`ReqBin/connector-spec`](https://github.com/ReqBin/connector-spec).

## Install

```bash
npm i @reqbin/connector
# or global CLI
npm i -g @reqbin/connector
